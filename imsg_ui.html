How this works

Messages are read from the Messages database on this Mac. Nothing is written to it.

Each column polls independently. Contacts you aren't watching stay idle.

Two things leave your machine: a sample of your own sent messages when learning a voice, and recent thread context when drafting.

Stop the server with Ctrl-C in Terminal.
